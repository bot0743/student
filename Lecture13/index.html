DevOps — культура и практики

DevOps объединяет разработку (Development) и эксплуатацию (Operations). Цель: сократить время от идеи до продакшена, сохраняя качество и надёжность.

Ключевые принципы: автоматизация всего, непрерывная интеграция и доставка, совместная ответственность, быстрая обратная связь, мониторинг и логирование.

Безопасность встроена

DevSecOps: безопасность в пайплайне

SAST

Статический анализ кода (SonarQube, Checkmarx) на каждый коммит.

DAST

Динамическое сканирование работающего приложения (OWASP ZAP).

SCA

Анализ зависимостей (Snyk, OWASP Dependency-Check).

Задача тестировщика — настроить эти инструменты так, чтобы они ловили реальные уязвимости, но не блокировали разработку ложными срабатываниями.

Практика · GitHub Actions

Создаём простой CI/CD пайплайн

Добавьте в корень репозитория файл .github/workflows/ci.yml:

name: CI
on: [push]

jobs:
  build-and-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Lint
        run: echo "Linting..." # замените на реальную команду
      - name: Run unit tests
        run: echo "Running tests..."

После пуша перейдите на вкладку Actions в репозитории — увидите выполнение workflow.

Это начало большого пути: сюда можно добавлять реальные тесты, статический анализ, сборку Docker, деплой.
