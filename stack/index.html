1991 · Первый публичный релиз

Python выходит в свет. Он вырос из языка ABC — учебного языка с чистой и читаемой архитектурой, но непригодного для работы с сетью и файловой системой.

Название

Не имеет отношения к змеям. Гвидо был фанатом группы Monty Python и назвал язык в честь шоу «Летающий цирк Монти Пайтона».

Программирование должно приносить удовольствие, а не быть мучением.

Эта философия хорошо иллюстрируется названием языка и лежит в основе всего дизайна Python.

Компонент 2 · Flask

Три причины выбора Flask

01

Прозрачность

Flask даёт понять, как на самом деле работает веб-приложение: путь запроса от браузера до сервера, формирование ответа, работа сессии.

Критически важно для будущих тестировщиков.

02

Гибкость в выборе БД

Можно работать с SQLite через стандартный модуль sqlite3, с MySQL через mysql-connector-python или использовать SQLAlchemy.

Это позволяет сравнить разные подходы в одном проекте.

03

Простота тестирования

Встроенный тестовый клиент позволяет отправлять запросы к приложению без запуска реального сервера.

В сочетании с pytest это даёт очень удобный workflow.

Первоапрельская шутка

Армин Ронахер и коллеги хотели показать, что микрофреймворк — не оксюморон. Шутка оказалась настолько удачной, что превратилась в один из самых популярных фреймворков Python.

Без батареек

Flask не включает базу данных, ORM или систему аутентификации — всё это подключается отдельно. Именно поэтому он идеален для обучения: вы видите, из чего собирается веб-приложение.

Компонент 3 · Базы данных

SQLite — встраиваемая реляционная БД

Не работает как отдельный серверный процесс. Вся база хранится в одном файле, который можно скопировать, отправить по почте или положить в систему контроля версий.

  • 1Нулевая настройка. Не нужно устанавливать сервер, настраивать пользователей и порты. Создаёте файл — и работаете.
  • 2Полная поддержка ACID — атомарность, согласованность, изоляция и долговечность транзакций, как во «взрослых» СУБД.
  • 3Идеальна для тестирования. Тесты запускаются на изолированной копии базы, которая создаётся и удаляется для каждого теста.
  • 4Высокая скорость чтения. Бенчмарки 2025 года показывают: SQLite обгоняет MySQL на чтении при малой конкурентности.

В каждом смартфоне

Используется и на iOS, и на Android. Вероятно, самая распространённая база данных в мире.

В авионике

Используется в самолётах Airbus A350 — одна из немногих баз, сертифицированных для авионики.

Без администратора

База «самообслуживается» — идеальна для встраиваемых систем и учебных проектов.

Компонент 3 · Базы данных

MySQL — полноценная серверная СУБД

Работает как отдельная служба. Приложения подключаются к ней по сети, а не работают с файлом напрямую.

01

Высокая конкурентность

Если несколько пользователей одновременно записывают данные, MySQL справляется лучше SQLite.

02

Масштабирование

Поддерживает репликацию, кластеризацию и шардирование — может расти вместе с нагрузкой.

03

Близость к production

В реальных проектах вы чаще встретите MySQL, PostgreSQL или аналогичные серверные СУБД.

Компонент 3 · Базы данных

Гибридная стратегия проекта

SQLite

Разработка и юнит-тесты
  • Быстро — не требует инфраструктуры
  • Изолированно — своя база на каждый тест
  • База может создаваться в оперативной памяти
  • Уничтожается после завершения тестов
  • Гарантирует, что тесты не влияют друг на друга

MySQL

Интеграция и демонстрация
  • Показывает поведение приложения в условиях, близких к реальным
  • Проверка работы при высокой конкурентности
  • Демонстрация сетевого подключения к БД
  • Отработка миграции между СУБД
  • Приближает проект к production-сценарию

Что это даёт: вы научитесь адаптировать код под разные СУБД — навык, который высоко ценится в индустрии. Тестировщик, умеющий работать с разными базами данных и понимающий их различия, стоит дороже и ценится больше.

Компонент 4 · Фронтенд

HTML — структура веб-страницы

HyperText Markup Language — язык разметки, определяющий структуру страницы: заголовки, параграфы, формы, таблицы, ссылки.

В проекте

Формы ввода данных — регистрация, отправка заявки. Навигация между страницами. Семантическая разметка.

Для тестирования

Атрибуты id, class, name — «якоря», за которые цепляются Selenium-тесты.

Чем лучше размечена страница, тем проще писать автоматические тесты. Если разработчик не уделил внимания разметке, тестировщику приходится писать хрупкие селекторы, которые ломаются при малейшем изменении вёрстки.

<!-- форма регистрации --> <form action="/register" method="post"> <label for="email">Email</label> <input type="email" id="email" name="email" required> <button type="submit" id="submit-btn"> Зарегистрироваться </button> </form>

Компонент 4 · Фронтенд

CSS — внешний вид и адаптивность

Cascading Style Sheets отвечает за цвета, шрифты, отступы, расположение элементов и адаптивность под разные экраны.

  • ✓Визуальные регрессии — один из видов тестирования: после изменения стилей страница может «поехать».
  • ✓Доступность (accessibility) — контрастность, размеры шрифтов, читаемость — всё это влияет на качество продукта.
  • ✓Скриншот-тесты — CSS создаёт точки для автоматизированной проверки визуальной части.

Разделение структуры и представления

CSS появился только в 1996 году — до этого стили задавались прямо в HTML-тегах. Это значит, что разделение структуры и представления — относительно молодая идея, но она себя полностью оправдала.

JavaScript — интерактивность, но дозированно

Почему JavaScript не больше?

Проект учебный. Мы хотим, чтобы вы понимали, как работает backend, а не прятали всю логику в браузере. Кроме того, чем меньше JavaScript, тем проще тестировать приложение: меньше асинхронности, меньше «плавающих» багов.

1995 · Брендан Айк · 10 дней

Изначально назывался Mocha, потом LiveScript, и только потом — JavaScript, причём в маркетинговых целях, чтобы ассоциироваться с Java. Никакого отношения к Java он не имеет.

Тестирование · Уровень 1

Юнит-тестирование — стандарт pytest

Фреймворк для тестирования Python-кода, который позволяет писать тесты в виде простых функций с assert-ами.

  • 1Создаёте задачу и проверяете, что её заголовок совпадает с ожидаемым.
  • 2Проверяете, что статус выполнения по умолчанию — ложный.
  • 3Фикстуры готовят окружение: тестовое приложение Flask, тестовую базу SQLite.
  • 4База может создаваться в оперативной памяти и уничтожаться после тестов — изоляция и скорость.
# tests/test_tasks.py def test_task_title(client): # создаём задачу r = client.post("/tasks", json={"title": "Написать ТЗ"}) data = r.get_json() assert data["title"] == "Написать ТЗ" assert data["done"] is False
Тестирование · Уровень 2

Интеграционное тестирование

Проверяет, как разные части системы работают вместе: Flask-приложение корректно сохраняет данные в базу, API возвращает правильный JSON, аутентификация работает совместно с сессиями.

Тестовый клиент Flask

Позволяет отправлять HTTP-запросы к приложению без запуска реального сервера. Быстро, удобно, воспроизводимо.

# отправляем POST-запрос к приложению def test_create_task(client): response = client.post( "/tasks", json={"title": "Новая задача"} ) # проверяем код ответа assert response.status_code == 201 # проверяем тело ответа body = response.get_json() assert body["title"] == "Новая задача"
Тестирование · Уровень 3

Сквозное end-to-end тестирование

Selenium — инструмент для автоматизации браузера. Имитирует действия реального пользователя: открыть страницу, заполнить форму, нажать кнопку, проверить результат.

Минусы

Самый «дорогой» вид тестов: медленные, хрупкие, требуют запущенного браузера.

Плюсы

Дают максимальную уверенность, что система работает так, как ожидает пользователь.

# открываем главную страницу driver.get("http://localhost:5000") # находим поле ввода по имени field = driver.find_element( By.NAME, "title" ) field.send_keys("Купить хлеб") # находим кнопку по идентификатору driver.find_element( By.ID, "add-btn" ).click() # проверяем, что текст появился assert "Купить хлеб" in driver.page_source

Безопасность · 152-ФЗ

Как стек соотносится с требованиями 152-ФЗ

01

Аутентификация и хеширование

Flask не имеет встроенной аутентификации, но даёт гибкие механизмы. Пароли — через werkzeug.security.

Когда пользователь регистрируется, сохраняется только хеш. При входе — хеш сравнивается с сохранённым.

02

Защита от SQL-инъекций

И SQLite, и MySQL поддерживают параметризованные запросы.

Никогда не используйте конкатенацию строк для формирования SQL-запросов — это классическая уязвимость.

03

Секретные ключи и сессии

Flask использует SECRET_KEY для подписи сессионных cookie.

Ключ не должен попадать в репозиторий — только переменные окружения или конфиги вне Git.

04

Логирование и аудит

Для соблюдения 152-ФЗ важно фиксировать доступ к персональным данным.

Flask позволяет легко добавить логирование всех запросов: кто, когда и к каким данным обращался.

Важно: пароли не хранятся в открытом виде. Даже если злоумышленник получит доступ к базе, он не сможет восстановить пароли. Проверка этих требований — часть тестирования безопасности.
